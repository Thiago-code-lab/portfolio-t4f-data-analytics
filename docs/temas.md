# Tema e escopo

**Portfólio de Dados — T4F Performance | Tour4Friends**, ligado ao Projeto Integrador V e à disciplina Metodologias para Projetos de Big Data Analytics da Fatec Ipiranga.

O portfólio apresenta processo, análise, evidência metodológica e comunicação profissional. A aplicação permanece no repositório original. Há uma demonstração principal e uma base acadêmica complementar, com naturezas, cortes e moedas explicitamente separados.
